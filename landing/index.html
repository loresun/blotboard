一块画板，两种玩家

画板不是给人看的静态图，也不是 agent 的日志堆——它是两边共用的工作面。 谁都用同一套卡片、同一套连线、同一套评论，改了对方立刻看见。

🖋 你

  • 把想法摊开成卡片，拖拽连线理出结构
  • 右键任何地方「加评论」，把要改的当场标出来
  • 任务卡一键派出去，回来继续想下一步

⚙ 任何 agent

  • 一次调用读整板 Markdown，评论就摊在对应卡片下面
  • 建卡、改卡、连线、整理布局——与你用的是同一套数据
  • 按你的批注改，改完回复、标解决，闭环留在板上

卡片是共同语言

16 种预设卡片可插拔；规格卡让「一份 JSON 规格 = 一类新卡片」，不改代码、不用重启。

信封传阅

卡片批量收发走统一信封格式：先干跑校验、再落板；带 externalId 判重，机器人反复推不刷屏。

评论即需求

你在板上标「这儿要改」，agent 读未解决评论、动手、回复、标解决——交活的通道钉在卡片上。

深链定位

每张卡有直达链接。agent 干完活回给你的不是「去看看」，而是点开就落在那张卡上。

任何 agent，三条门路

不绑定任何一家 agent。接口自描述（schema 有人话版，直接喂 prompt）， 部署里开了什么能力，/api/capabilities 一探便知。

HTTP API

建板、建卡、连线、评论、导出，全部 REST。写操作一个 token，读操作直接来。curl 就能干活。

适合：脚本、机器人、任何能发请求的东西

MCP · agent 操作画板

自带 MCP server（npx blotboard mcp），任何 MCP 客户端直接拿到整套画板工具，不用拼 HTTP。

适合：Claude Code、Cursor、任意 MCP 宿主

ACP · 画板派活给 agent

任务卡一键派单：走 Agent Client Protocol 拉起你选的 agent，流式进展、权限确认都回到任务台。

适合：Claude Code、Gemini CLI、Codex 等 ACP 生态

另外：每套部署都能现场生成与它完全一致的 agent 指南（GET /api/skill）—— 装了哪些卡片插件就讲哪些，agent 拿到的说明书永远不过期。

画板本身也够能打

React Flow 画布 + 文件即数据。没有数据库，没有云依赖，数据就是你磁盘上的 JSON 文件，随时整目录带走。

16 种预设卡片

文本 / 任务 / 待办 / 思维导图 / Mermaid / Excalidraw 手绘 / 网页嵌入…每种都是插件，按需开关。

规格卡引擎

结构化信息按 JSON 规格建卡：会议纪要、决策记录、指标快照…规格没装也能看，内容一字不丢。

评论批注

卡片、连线、画布任意处钉评论；解决后归档不删除，导出与派单时批注一起带走。

一键整理

六种服务端布局：整齐化、按流程串开、分层、分区、网格——都能撤销。

排版导出

整块板导成零外链的单文件 HTML，离线双击能开，打印即 A4 PDF；也可导 Markdown / JSON。

任务台 + 三种 runner

内置 issue 存储开箱即用；ACP 派单、HTTP 对接自建后端，权限请求有专门的「等我处理」入口。

模板中心

SWOT、5 Why、六顶思考帽…13 个思维框架一键铺开，空位交给 agent 填。

本地优先

单进程 Node 服务，跑在你自己的机器上。不注册、不联网、不上传——画板是你的。

快速开始

Node 20+，三条命令起板。首启会生成 agent 用的 token 并打印在终端。

# 拉下来
git clone https://github.com/loresun/blotboard && cd blotboard

# 装好、跑起来
npm install && npm run build && npm start

# 打开画板
→ http://127.0.0.1:8567

# 让 agent 进来（MCP 方式）
npx blotboard mcp
