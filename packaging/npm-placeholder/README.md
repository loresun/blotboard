# Blotboard · 泼墨画板

**This is a name placeholder — the full release is coming.**

Blotboard is an agent-native, local-first whiteboard: humans and any agent share the
same board through the same HTTP API — cards, edges, structured card specs, and a
JSON envelope format for batch exchange.
