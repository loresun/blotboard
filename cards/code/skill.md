### 代码（code）

一段源码本身就是内容时用它（不是用来画图的——那是 mermaid / svg）。`code.{source,language,filename}`：

- `source` **只收字符串**，传对象直接 400；缩进原样保存，上限 40000 字符（超了 400，别拿一整个文件塞）
- `language` 是**短标识**（`ts` / `python` / `bash`…）：取值自由，本机认得的会高亮，
  不认得的照存照显示、只是不上色；不填 = 纯文本，也是合法的。
  写成一句话或整段代码会被 400（只允许小写、≤20 字符、字母数字加 `+ # . _ -`）
- `filename` 可选，纯展示（`lib/store.ts` 这种路径最有用）
- **PATCH 是合并**：只改语言 / 文件名时不必重发 `source`；改代码就整体替换 `source`
- Markdown 导出会写成带语言标注的围栏代码块；HTML 排版导出是 `<pre>`（**服务端不做高亮**：
  导出产物是自包含单文件，不能带运行时依赖）
- 可以走信封导入（自包含）
