### 表格（table）

**手上已经是一段 Markdown 表格或 CSV 就直接塞，别自己解析**——这张卡收三种输入形态，
建卡（POST）和改卡（PATCH）都认：

```jsonc
{"type":"table","title":"季度收入","table":{"markdown":"| 季度 | 收入 |\n| --- | ---: |\n| Q1 | 120 |"}}
{"type":"table","table":{"csv":"季度,收入\nQ1,120\nQ2,138"}}          // 也认 TSV / 分号，自动判分隔符
{"type":"table","table":{"columns":[{"key":"q","label":"季度"},{"key":"v","label":"收入","align":"right"}],
                          "rows":[{"q":"Q1","v":"120"},["Q2","138"]]}}   // 行也可以按列顺序给数组
```

- **一次只给一种形态**：同时给 `markdown` 和 `csv`（或文本形态 + `columns/rows`）会 400，
  免得两份数据对不上还得猜用哪份
- 上限 **50 列 × 500 行**，单元格 ≤2000 字符；超了当场 400 报实际数字（不会静默截断）
- 单元格是**纯文本**：数字 / 布尔可以直接给，存进去会变成文本
- Markdown 表格的对齐（`:---:`）会被读成列的 `align`；单元格里的竖线要写成 `\|`
- CSV 按 RFC4180：带分隔符或换行的字段用双引号包住，字段里的引号写成 `""`
- **PATCH 是合并**：`{"table":{"caption":"…"}}` 只改标题；给了任一种表格形态才整体替换表格
- 导出：Markdown 出 Markdown 表格，HTML 排版出真表格
- 可以走信封导入（自包含）
