一句话：**把想法摊开成卡片、拖拽连线、右键批注——这是给人的那半边；界面上每一件能做的事都有一个对应的 API——这是给 agent 的那半边。你们看到的是同一块板。**

市面上的白板是给人用的，agent 进不来；agent 的记忆是给模型用的，人看不见。泼墨画板想要的是中间那块地：人负责思考、判断、批注，agent 负责建卡、改卡、按批注改、把任务领走再把产出送回来。谁改了什么，另一边下一次刷新就看得见。

## 三条它坚持的事

**① 本地优先。** 数据就是你磁盘上的 JSON 文件，一块板一个文件，原子写。没有云、没有账号、不联网。想备份就复制那个目录；想迁走就把目录搬到另一台机器。服务默认只接受本机、私网和 Tailscale 直连。

**② 卡片是插件。** 21 种卡片（文本、任务、图片、代码、表格、图表、思维导图、网页嵌入……）每一种都是一个独立目录，在「卡片中心」里按需开关。停用只挡新建，**已有的卡片与数据一个字段都不会丢**——这条是这个项目的第一铁律，测试里有逐字节往返的用例守着。

**③ agent 不用你教。** 接口自描述（`GET /api/capabilities`），指南按这台部署实际启用的东西现场拼装（`GET /api/skill`）——装了什么就讲什么，说明书永远不会跟部署漂移。

## 它适合装什么

- **想清楚一件事**：一堆碎想法摊开 → 连出因果 → 整理成流程 → 读一遍 → 导出成一份文档
- **一个项目的全景**：需求卡、任务卡、参考链接、会议纪要、决策记录摆在一块板上，子画板按模块分开
- **给 agent 的工作面**：你在卡片上写清楚要什么，agent 建卡回填、把任务领走执行，产出回到同一张卡
- **结构化的小库**：会议纪要 / 选题 / 排障记录 / 模型实测……用「规格卡」存成有字段的结构，能筛能导能批量收发

## 它不适合什么

不是实时协作白板（没有多人光标、没有冲突合并，靠的是轮询 + 整块板的乐观并发）。不是画图工具（要自由手绘有内嵌的 Excalidraw 卡，但它不跟 Figma 比）。也不调任何大模型——画板本体零外部依赖，AI 能力全都在你接进来的那个 agent 那边。
