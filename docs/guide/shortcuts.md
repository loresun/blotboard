画布左下角的 **?** 按钮，或在画布上按 `?`，可随时打开快捷键说明。下表的 `⌘` 在 Windows / Linux 上使用 `Ctrl`。

**键盘归属**：输入框、正文编辑、弹窗、嵌入网页保留自己的键盘与原生撤销。完成编辑、回到画布后再撤销画板操作；中文输入法组词期间不会触发画板快捷键。

## 工具与视野

| 键 | 干什么 |
| --- | --- |
| `V` | 选择工具：左键框选，中键 / 右键拖动平移 |
| `H` | 抓手工具：左键拖动平移画布 |
| 按住 `空格` | 临时抓手（松开回到原来的工具） |
| `⌘ +` / `⌘ -` | 放大 / 缩小 |
| `⌘` + 滚轮 | 以光标为中心缩放 |
| 滚轮 / 双指 | 平移 |

> 抓手模式下（含按住空格的临时抓手）卡片既拖不走也拉不出线——手型光标承诺的是「抓的是画布」。这是刻意的：同一个手势在卡片上和空白处做两件事，是画布类工具最容易踩的坑。

## 选择与编辑

| 键 | 干什么 |
| --- | --- |
| 双击空白处 | 新建文本卡片 |
| 双击卡片 | 编辑 |
| `⌘/Ctrl + Enter` | 卡面「编辑文本」时保存（`Esc` 放弃）|
| `⌘A` | 全选当前画板的卡片 |
| `⌘C` | 复制选中的卡片（跨画板、跨窗口都能粘） |
| `⌘V` | 粘贴：卡片 > 图片 / PDF > 纯链接 |
| `Delete` / `Backspace` | 删除选中的卡片或连线（多选会先问一句） |
| `⌘Z` / `Ctrl Z` | 撤销上一步画板操作 |
| `⌘ Shift Z` / `Ctrl Shift Z` / `Ctrl Y` | 重做已撤销的画板操作 |
| `Esc` | 清除画布选择 |
| 右键 | 卡片 / 连线 / 空白处各有一份完整菜单 |

修改历史可在顶栏「历史」中查看，也可用快捷键逐步撤销与重做。删除后右下角提示条的「撤销」同样可用。

## 通读与批注

| 键 | 干什么 |
| --- | --- |
| `R` | 阅读模式。选中了某张卡就从那张开始，没选中就从阅读顺序的第一张开始通读 |
| `C` | 给选中的那张卡加评论 |
| `⌘F` | 搜索 / 筛选（回车逐个跳命中，`Shift` + 回车往回跳） |
| `Esc` | 退出当前这层：编辑 → 卡片、大纲 → 画布、弹窗 → 关闭 |

阅读模式里：`←` `→` 翻卡，`F` 进 / 出全屏，图类卡片 `+` `-` 缩放（10% – 1000%）、`0` 回到 100%。正文里嵌了别人的页面时（网页卡、PDF），头上会多一个**键盘归属**开关——默认 `←` `→` 还是翻卡，按一下才把键盘交给那张 PPT。

## 大纲视图里

`↑` `↓` 上下移动，`Enter` 进入行内编辑，`⌘Enter` 保存，`Esc` 回画布。

## 上传接受的文件

图片、PDF、以及音视频（mp4 / mov / mp3 / m4a 等）。判定按**扩展名**——浏览器给的 MIME 对 .m4a / .mov 经常是空串，靠它判会把正常文件挡在门外。
