## 打不开，或者端口不对

默认地址是 `http://127.0.0.1:8567`，**端口被占会自动顺延**（8568、8569……）。实际端口有三个准确来源：数据目录下的 `port` 文件、`GET /api/health` 的返回、启动日志。别把端口写死在任何脚本里。

`GET /api/health` 还会告诉你：数据目录在哪、有多少块板、任务后端是哪种、token 配没配。排查从这一条开始。

## 从别的设备打不开

服务默认只接受**本机 / 私网 / Tailscale 直连**，其余一律 403。这是刻意的：写接口没有应用层的用户体系，网络边界就是唯一的边界。要从外面访问，正确做法是在前面加一层反向代理并自己做认证，而不是把这道闸门关掉。

## 卡片好像丢了

按这个顺序找：

1. 是不是**开着筛选**？工具箱收起来时筛选仍然生效，小按钮上有个点提示
2. 是不是在**折叠起来的分组框**里？框折叠后只剩一个框
3. 是不是被挪进了**子画板**？左栏里看这块板底下有没有子板
4. 视口飘到很远的地方了？顶栏中间的「适应内容」一键拉回来
5. 真的被删了？顶栏「历史」里挑一份改动之前的快照回滚

## agent 改完我这边没变

画板会自己轮询：跟着任务时 2 秒、抽屉开着 3 秒、平时 15 秒；**页面切到后台会完全停掉**，切回来立刻补一次。等不及就点顶栏中间的刷新。

## agent 说没有权限 / 403

写接口要 token。首次启动生成在数据目录的 `token` 文件里，也可以用环境变量显式指定。读接口不需要。浏览器里操作不涉及这个——同源页面自带写权限。

## 工具条上找不到某种卡片

三种可能：

- 那个卡片包在**卡片中心**里被停用了
- 它在「**更多**」里（结构化与组织类、以及要配外部服务的来源类）
- 它依赖的**外部服务没配**（资料卡要知识库、图书卡要书库）——没配就整个入口隐藏，免得点了只会报错

## 整理之后布局乱了

右下角提示条上有「**撤销**」，点它回到整理之前。要是提示条已经消失，顶栏「历史」里也有整理之前的快照。

顺带一提：**分组框和框里的卡片不参与整理**——如果你想让某几张卡永远保持你摆的样子，把它们圈进一个框。

## 网页卡嵌不进来

嵌入受白名单限制——不是所有站点都允许被别人的页面嵌（很多站点自己就用响应头拒绝了）。编辑器里输地址时旁边会预判能不能嵌。嵌不了的退一步用链接卡。

## 数据在哪儿、怎么备份

在数据目录的 `boards/` 下，一块板一个 JSON 文件。备份就是复制那个目录，迁移就是搬过去。上传的图片 / PDF / 音视频在 `uploads/`，快照在 `checkpoints/`。

## 还有问题

`npm run doctor` 会打一份可以直接贴给别人看的诊断报告（只读，不改任何东西）。
