评论不是留言板，是这块板上**最顺手的派活通道**。

## 怎么钉

- 选中一张卡按 `C`
- 右键卡片 / 连线 / 画布空白处 →「加评论」

钉在空白处的评论有自己的坐标，就停在你点的那个位置——「这一片太挤了」这种意见本来就不属于某一张卡。

## 顶栏那个数字

顶栏「评论」上的角标是**未解决**的条数。板上还欠着几件事，不点开也看得见。点开是评论抽屉：按未解决 / 已解决分，点一条跳到它钉着的地方。

## 一条评论的一生

```
你钉一条  →  agent 读未解决的评论  →  动手改  →  在同一条下面回复「改完了，做了 A 和 B」  →  标记解决
```

三件事都在板上：需求、改动、结论。半年后回来看这块板，还能看出当初为什么改成这样。

## 给 agent 说什么

评论正文越具体越好，但不用写成规格书。这几种都好使：

- 「这段结论太满了，加一句限制条件」
- 「把这张卡拆成三张：现状 / 阻碍 / 下一步」
- 「这条线应该是阻塞不是关联」
- 「按这张卡的清单，把缺的那四张卡补上」

agent 那边一句「看看这块板有哪些待处理评论，按评论改」就够——它会把未解决的读完、逐条动手、逐条回复。

## 和任务卡的分工

评论适合「**在这块板上改点什么**」。要「**去外面干一件事再把结果带回来**」——写代码、跑脚本、查资料——那是任务卡的活，见 [任务与 Issue](/docs?doc=tasks)。
