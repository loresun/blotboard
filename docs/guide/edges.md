从卡片边缘的小圆点拖到另一张卡上就是一条线。选中它（点一下）或右键，能改三样东西。

## 一、关系（五种）

| 关系 | 意思 |
| --- | --- |
| **关联** | 这两件事有关（默认） |
| **阻塞** | A 卡着 B，B 得等 |
| **前置** | 先 A 后 B 的顺序 |
| **引用** | B 引用了 A 的内容 |
| **产出** | A 做完产出了 B |

## 二、关系强弱（1-5）与关系标签

强弱**是语义不是线宽**。它有实际用途：分层重排和子图分簇会拿它当权重，导出的 Markdown / HTML / 信封里都带着它。「这两张卡只是顺带提了一句」和「这条是主干」，摆出来会不一样。

关系标签是一行自由文字，写在线上——「因为限流」「等设计稿」这种说明比五种关系里挑一种精确得多。

标签的摆法有三条约定，都是为了**读得出来**：

- 标签推到线**旁边**，不压在线身上
- 同一对卡片之间有好几条线时，标签沿着曲线错开（只挪标签，线的走向一点没动）
- 长标签先截断，**选中那条线时展开完整文字**（悬停也能看全）

标签**还不会主动躲开第三张卡或别的标签**。真正的避障要先换成折线路由，那会改变画板上现有每一条线的走向，是一次独立的改动——目前的做法是：连线密的地方靠[整理](/docs?doc=organize)先把卡摆开，标签自然就不挤了。

## 三、外观三件套

颜色、线型（实线 / 虚线 / 点线）、粗细。纯视觉，不参与任何计算。想让一块板一眼看出「主干 vs 旁支」，改这个最直接。

## 连线怎么影响其它功能

- **大纲缩进**：一张卡的「父」= 唯一且更靠前的那个上游，整张大纲的层级都由连线推出来
  （**阅读模式不看连线**，它按摆放位置读——见 [几种看法](/docs?doc=views)）
- **整理**：分层 / 流程串开 / 子图分簇全靠连线；网格和类型分区则完全不看连线
- **聚焦模式**：只亮选中的卡和**直接相连**的那些
- **导出**：Markdown 与 HTML 里会把关系、强弱、标签一并写出来

## 小提示

- 连线连的是卡片不是某条边——拖动卡片时线会自己找最近的边贴上去
- 想删线：选中按 `Delete`，或者右键删除。同样可撤销
- 一张卡上的线太多说明它承担了太多角色，多半该拆成两张
