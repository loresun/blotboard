Comments aren't a message board — they're **the handiest way to hand out work** on this board.

## How to pin one

- Select a card and press `C`
- Right-click a card / an edge / empty canvas → "Add comment"

A comment pinned on empty space has its own coordinates and stays exactly where you clicked — an opinion like "this area is too crowded" never belonged to any single card anyway.

## That number in the top bar

The badge on **Comments** in the top bar counts **unresolved** items. How many things the board still owes you is visible without opening anything. Open it and you get the comment drawer: split into unresolved and resolved, click one to jump to where it's pinned.

## The life of a comment

```
you pin one  →  agent reads the unresolved comments  →  makes the change  →  replies underneath: "done, did A and B"  →  marks it resolved
```

All three things stay on the board: the request, the change, the conclusion. Come back to this board in six months and you can still see why it ended up this way.

## What to tell the agent

The more specific the better, but you don't have to write a spec. All of these work:

- "This conclusion is too absolute, add a caveat"
- "Split this card into three: current state / obstacle / next step"
- "This edge should be blocks, not related"
- "Following the checklist on this card, add the four cards that are missing"

On the agent's side, "look at the pending comments on this board and act on them" is enough — it reads every unresolved one, works through them, and replies to each.

## Division of labour with task cards

Comments suit "**change something on this board**". "**Go do something out there and bring the result back**" — write code, run a script, look something up — is a task card's job; see [Tasks and Issues](/docs?doc=tasks).
