板子一大就想「把这几张归到一起」。有两种做法，选错了以后会很别扭。

## 分组框（frame）：就地圈一块地

在画布上画一个框，卡片拖进去就归它。

- 卡还在**本板上**，只是多了一个「我在哪个框里」的记号
- 拖框 = 整摊跟着走
- 框可以**折叠**，收起来只剩一个框和数量
- **整理时框和框里的卡会被跳过**——那是你手工圈的分区，重排会把它拆散
- 阅读模式把框读成**一章**：读到一个框，接着读的就是它框住的那几张（目录里也缩进挂在它下面）

### 「框里明明有卡，怎么写着 0 张」

因为归属只认**卡片自己身上的记号**，不认两个矩形谁压着谁。把卡拖进框会自动打上这个记号；但从别处导进来的一批卡、或者 agent 整板改写之后落下的卡，可能只是坐标落在框里，记号还是空的。

这时框上会多一句「收纳 N 张」，点它就把这 N 张收进来（右键框、阅读模式里也有同一颗按钮）。

- 只收**还没归属任何框**的自由卡；已经归属别的框的卡不会被抢走——那是你明确表达过的归属
- 判定是「卡片的**中心点**落在框里」
- 这是一次批量改动：系统会先给整块板打一份快照，提示条上给一颗**撤销**

系统**不会**自己替你收。视觉上重叠不等于归属，凭几何默默改一批卡的归属，比让你多点一下要贵得多。

什么时候用：这几张卡要一起搬、一起看，但还属于这块板的主线。比如「第一阶段」「待定的那批」「反例」。

## 子画板卡（board）：挪进另一块板

在这块板上放一张卡，卡指向**另一块板**；双击卡片下钻进去，顶栏会出现返回路径。

- 卡片真的搬到了另一块板上，本板只剩一张卡的位置
- 子板在左栏里缩进显示，分组自动继承
- 卡面上能看到那块板的缩略图与数量

什么时候用：这一摊已经足够复杂，值得有自己的一整块画布；或者你只是想让它**离开视线**，主板保持干净。

## 一句话选择

**要「一起搬」用框，要「挪出视线」用子画板。**

## 板子多了怎么找

三个地方：

- **左栏搜索** —— 同时搜板名、分组名和卡片正文
- **画板导航页** —— 左边分组、右边一块块板按时间排，比在左栏的树里翻快得多
- **面包屑** —— 下钻进子画板后，顶栏左边会出现回去的路径

板的分组在左栏新建按钮右边的箭头里管：新建分组、把板挪进某个分组、重命名分组、解散分组。
