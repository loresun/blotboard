顶栏「**整理**」。十一种摆法，分四档；**每一次整理都能撤销**——右下角提示条上就有「撤销」，点它卡片回到原来的位置。

> 整理是纯算法，服务端和界面用的是同一套函数。agent 走 `POST /api/boards/{id}/tidy` 得到的结果与你点菜单完全一致。

## 保结构的（日常用这个）

**整齐化** —— 对齐行列、理顺交叉的线、推开重叠，**卡片还在你放的位置附近**。它不重排结构，只是把手摆得歪七扭八的板子扶正。九成场景用它。

## 按连线重排（会推翻当前布局）

- **按流程串开** —— 每条从起点走到终点的链拉成一行，从左到右就是执行顺序，分支往下错开。**拿画板搭工作流用这个**
- **横向分层** / **纵向分层** —— 按连线方向分层重排。分层是按「秩」压扁的，看不出路径怎么走；要看路径用上面的流程模式

## 不看连线，只看卡片本身

- **按类型分区** —— 同类聚成一区，区与区之间留白
- **网格铺开** —— 全部对齐铺成网格

## 按字段语义（把板当数据看）

- **时间线** —— 一天一列、同一天纵向堆叠。取时间的次序是「规格卡里第一个日期字段 → 任务卡推给执行方的时刻 → 建卡时间」，一个都取不到的排到最右边「未定时」区
- **看板分列** —— 按状态分列：任务卡按 idea / issued / running / done，规格卡按规格里的状态字段，其余按类型
- **四象限** —— 两个二值维度切成田字。维度**整块板只选一组**：有任务卡就用「重要 × 已开工」；否则取规格里前两个可枚举 / 数值字段；都没有就按「有无上游 × 有无下游」。归不了类的摆在右侧
- **泳道** —— 看板的二维版：行 = 卡片类型，列 = 状态。行列边界靠留白自解释
- **子图分簇** —— 按连线的连通分量把「这块板其实是几张图」摊开。一簇一张图

## 怎么挑

| 你想知道 | 用哪种 |
| --- | --- |
| 这堆东西怎么变整齐 | 整齐化 |
| 这条流程从哪走到哪 | 按流程串开 |
| 这块板里都有些什么 | 按类型分区 / 网格 |
| 这些事发生在什么时候 | 时间线 |
| 什么在做、什么做完了 | 看板分列 / 泳道 |
| 先干哪件 | 四象限 |
| 这块板是不是其实是三块 | 子图分簇 |

## 两条要知道的边界

- **分组框和框里的卡不参与整理** —— 那是你手工圈的分区，重排会拆散它
- 整理只动坐标，不改任何内容、不动连线的语义

## 乱板怎么选

- 还想保留原来分区：先用**整齐化**，它会保留已有列与行的基准，修整对齐和重叠。
- 完全散乱、先求整洁：用**网格铺开**；格距按最大卡片尺寸计算，不同大小的卡也有一致留白。
- 类型混在一起：用**按类型分区**，同类成组，组间留白更大。
- 想读清先后关系：用**横向/纵向分层**；分支、汇合用**流程**，互不相干的几张图用**子图分簇**。
- 需要按业务字段看：选时间线、看板、四象限或泳道。时间线按 **UTC 自然日**分列，各台机器得到一致结果；四象限只用有效数值或枚举，缺失数据留在未归类区域。

分组框及真正属于框内的卡保持原位。自由卡整理后会整体避开固定区域，不会把现有框盖住；这种整体平移不改变已计算好的内部对齐、间距或连线层级。超出画布坐标范围的布局会拒绝执行，不会把所有卡挤在边界上。

## 放心尝试，再连续撤回

每次真正改变位置的整理都独立记一条历史。可以连续试「网格 → 横向分层 → 看板」，然后用 Ctrl/Cmd+Z 逐步回去；Ctrl/Cmd+Shift+Z 重做，Windows/Linux 也可 Ctrl+Y。历史面板保留操作列表，刷新后仍可继续。

重复执行同一模式且位置已稳定时，不会制造空的撤销步骤。编辑文字时快捷键归文字编辑器，不会误撤回整块画板。具体保存容量与边界见[历史与回滚](/docs?doc=history)。
