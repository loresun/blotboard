画布左上方工具条的最后五项都是**开关**：有淡紫底色表示已开启。它们只改变怎么看、怎么拖、快捷按钮显不显示，不会删除或改写卡片正文。鼠标停在按钮上，或用键盘把焦点移到按钮上，会出现一张简短说明卡，并标出当前是“已开启”还是“已关闭”。

## 五个开关各管什么

| 开关 | 打开后发生什么 | 会不会改数据 |
| --- | --- | --- |
| **大纲** | 把当前画板按阅读顺序摊成一列，并按连线显示层级；可在大纲里改标题和正文 | 切换视图本身不改数据，在大纲里编辑会保存 |
| **聚焦** | 选中一张卡时，只突出它和直接相连的卡片，其余变淡 | 不改，只是临时降噪 |
| **对齐** | 拖到邻近卡片的边线、中线或等间距位置时自动贴齐，并显示参考线；缩放卡片时同样生效 | 只保存你最后拖到的位置和尺寸 |
| **网格** | 手动拖动或缩放时吸到画布的 22px 点阵 | 只保存量化后的坐标和尺寸 |
| **快捷条** | 选中卡片时，在卡片上方显示改色、阅读、评论、复制和删除 | 不改；关闭后右键和卡头 `⋯` 仍有完整功能 |

这些开关会记住你的选择，刷新页面后继续沿用。

## “对齐”和“网格”不是一回事

**对齐认邻居**：它关心“这张卡是否和旁边那张卡左边齐、中线齐、间距相等”。只有拖到最后几个像素时才会帮一下，默认开启，日常手感更自然。

拖动和缩放都认：**拖动**对齐的是整张卡摆在哪，六条边线、中线加等间距都参与；**缩放**对齐的是你手上那条边拉到哪——只有被拉的那条边（以及跟着走的中线）去贴邻居，对面那条边纹丝不动，所以一排卡片可以先对齐位置、再把宽度拉成一样齐。斜角手柄两个方向各贴各的。

**网格认点阵**：它不看邻居，只把位置和尺寸落到固定的 22px 刻度上。适合需要严格整齐坐标的板，默认关闭。

两个同时开启时，靠近邻居会优先按“对齐”吸附；没有命中邻居参考线的方向再按网格落点。

## 它也不是“整理 → 网格铺开”

- 工具条的**网格开关**只在你之后手动拖动或缩放某张卡时生效，不会突然移动整块板。
- 顶栏“**整理 → 网格铺开**”是一次整板操作：立即把全部自由卡片重新排成行列，会改变现有布局，但可以撤销。

日常建议：保持“对齐”和“快捷条”开启，“网格”关闭；需要严格坐标时再开网格。想一次收拾整块乱板，使用[十一种整理](/docs?doc=organize)。
