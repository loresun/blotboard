界面一共四片区域。认清楚它们各自回答什么问题，就不用满屏找按钮了。

## 顶栏：左边「去哪儿」，中间「怎么看」，右边「做什么」

顶栏上的东西不是按功能大小排的，是按**心智**分的三块：

| 位置 | 回答的问题 | 有什么 |
| --- | --- | --- |
| **左上角** | 我在哪儿？能去哪儿？ | 侧栏开关 · 站点导航（画板 / 导航 / 资源 / 任务台 / 帮助）· 子画板路径 · 板名 · 保存状态 |
| **正中** | 这块画布怎么看？ | 选择 / 抓手工具 · 缩放读数 · 适应内容 · 回到原点 · 立即刷新 |
| **右侧** | 对这块板做什么？ | ①内容：模板 / 卡片　②整理与导出：整理 / 阅读 / 导出　③协作与 Agent：评论 / 历史 / Agent |

**站点导航**里的五个页面是这个服务的全部页面：画板（这里）、画板导航（板多了按分组和时间翻）、资源库、任务台、以及你正在看的帮助。从画板出发点它们都是**新标签打开**——画布是工作面，点一下导航就把它顶掉太贵；子页面之间则是同标签切换。

**右侧三组**是按「这件事属于哪一类」分的胶囊，而不是一长排按钮：往板上放东西的（模板、卡片中心）、对整块板做一次的（整理、阅读、导出）、跟 agent 打交道的（评论、历史、派单）。窗口窄了字会先收起来只留图标，但**三块的分界一直在**——顶栏永远是「三块」而不是「八颗按钮」。

### 窗口窄了：命令收进「更多」，不会被挤出屏幕

顶栏放不下的时候，右边会出现一颗**更多**，按下面这个次序把命令收进去（收起来的一颗不少，全在那张菜单里）：

1. 先收**字**，只留图标；
2. 模板 / 卡片；
3. 历史 / 设置；
4. 整理 / 导出（**阅读留到最后**——通读整块板是这里最常按的一件事）；
5. 评论 / Agent（评论那个「还欠几条」的角标跟着挪到「更多」上）；
6. 最后一档：品牌字与存储胶囊让位，站点导航收成一颗（点开还是那七个页面），阅读也进菜单。

收到第几档是**量出来的**，不是按屏幕宽度猜的——板名多长、有没有子画板路径、界面是中文还是英文，这些同样吃宽度。所以同一个窗口宽度下，板名短的时候按钮更多，这是对的。手机竖屏（≤480px）还会再省一点像素：缩放读数收起来，`+` `−` 两颗还在。

## 左栏：画板列表 / 卡片列表

两个页签来回切：

- **画板**：全部板子按分组、按父子层级摊开；搜索框同时搜板名、分组名和**卡片正文**（正文命中会在下面单列一段，点一条直接跳到那块板的那张卡）
- **卡片**：当前这块板的卡片按类型分组列出来，点一条把视口挪过去；右键复制卡片 ID（给 agent 用的高频动作）

右边缘可以拖着改宽度，双击恢复默认。顶栏最左边那颗按钮、或者贴着边的那根细条，都能把它收起来。

## 工具箱：建卡与搜索

画布左上角浮着的那一条。上面一排是**建卡**入口（按卡片包注册表生成——停用一种卡片，这里的按钮当场消失），第三、四组收在「更多」里；后面跟着上传，再后面是五个开关：

- **大纲**：整块板摊成一列，按连线上下游缩进（见 [几种看法](/docs?doc=views)）
- **聚焦**：选中一张卡时只亮它和直接相连的卡，其余淡出
- **对齐**：拖动 / 缩放卡片时贴齐邻居的边线、中线与等间距位置，并画出参考线（默认开）
- **网格**：拖动 / 缩放时吸到画布的 22px 点阵，坐标严格取整（默认关）
- **快捷条**：选中卡片时在卡片上方浮一条快捷工具条。关掉什么都不少——卡头的 `⋯` 与右键菜单才是完整入口

两个吸附的区别与配合见 [画布辅助开关](/docs?doc=canvas-aids)。

工具条整条可以收成一颗小按钮（最右边那个箭头），画布留给内容；收起来之后搜索和筛选**仍然生效**，小按钮上会有个点提示你。

下面一行是搜索条（`⌘F`）：搜标题、正文、链接、Issue 号，还能按卡片类型筛。命中的卡片高亮、没命中的淡出，回车逐个跳。

## 画布本身

- 空白处**双击**新建卡片，**右键**出菜单（加评论 / 粘贴 / 全选……）
- 卡片**双击**进编辑，**右键**出完整菜单，卡头 `⋯` 是同一份
- 连线点一下选中，右键改关系 / 外观 / 强弱
- 滚轮或双指平移，`⌘` + 滚轮缩放

更多手势见 [快捷键与手势](/docs?doc=shortcuts)。
