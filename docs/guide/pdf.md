顶栏「导出」里头两项就是它：**导出 PDF**（用上次的设置直接出）和 **PDF 排版设置…**（带真实分页预览的面板）。

## 它跟「导出 HTML 再自己打印」有什么不同

以前要 PDF 得走三步：导出 HTML → 打开那个文件 → 按 Cmd+P。版式是屏幕样式凑合印的，分页由浏览器随手决定，页码和目录都没有。

现在**分页是画板自己算的**：纸张、页边距、字号、分栏、每页页脚、以及**带真实页码的目录**，全在排版这一步定死。设置面板右边那一页页纸不是示意图——它和打印出来的是同一份文档、同一次分页，所以「预览里第 3 页开头是这张卡」印出来就是第 3 页开头是这张卡。

## 一份 PDF 里保住了什么

- **链接还能点** —— 正文里的链接是真的链接注解，不是印在纸上的一行蓝字
- **文字能选能搜** —— 矢量文字，不是把每页截成图。一份二十页的板子几百 KB
- **图片按原图嵌进去** —— 图片、图表、流程图都在，导出前已经内联好，不依赖网络
- **卡片不跨页** —— 一张卡宁可整块挪到下一页，也不会被劈成两半（长到超过一整页的卡除外，那种会让它自己往下流）

## 走一遍

1. 顶栏「导出」→「**导出 PDF**」（想先调版面就点下面那项「PDF 排版设置…」）
2. 系统打印对话框弹出来，目的地选「**另存为 PDF**」
3. 存下来就完事了

对话框里三条对得上就行：

- **纸张选与设置里同一种** —— 这里选 A4 就在对话框里选 A4。选不一样浏览器会把整页缩放，字号和页边距就不是你定的那个了
- **「页眉和页脚」关掉** —— 页码由这份版面自己印，两套页码会打架
- **边距保持「默认」** —— 版面已经写死在纸张里，再叠一层边距会挤出空白页

> 为什么要过一道打印对话框：浏览器里没有别的办法既生成真 PDF、又保住可点的链接和可选的文字。绕开对话框的做法只有「把每页截成图」，那样得到的是一叠图片——链接点不动、文字选不中、体积还大好几倍。所以这一步不省。

## 设置面板

左边分三组，改任何一项右边立刻重排，页数当场变——省不省纸看数字就知道，不用先印一份试。

**纸张**：尺寸（A4 / A3 / Letter / Legal）· 方向（纵向 / 横向）· 页边距（窄 12mm / 标准 18mm / 宽 26mm）

**版面**：

| 项 | 说明 |
| --- | --- |
| 字号 | 小 / 标准 / 大。整份文档按比例缩放，不是只改正文 |
| 分栏 | 一栏 / 两栏。**卡片多、正文短的板子分两栏很省纸**；宽图与宽表会自动横跨整页 |
| 封面 | 板名、分组、统计、导出时刻 |
| 目录 | 带**真实页码**，条目就是卡片编号 |
| 页脚页码 | 每页底下印板名与「第 n / N 页」 |
| 每张卡另起一页 | 做逐张过目的评审稿时用 |

**内容**：

| 项 | 说明 |
| --- | --- |
| 范围 | 整块板 / 筛选命中的那批（口径与画布一致）/ 画布上选中的那几张 |
| 带上评论 | 做评审版，未解决的批注跟着卡片一起印 |
| 印图片 | 关掉只省墨，图注与卡片结构照旧 |
| 链接后附网址 | 纸上的链接点不动，把网址跟在后面才抄得到——真要打印出来给人看时打开它 |

设置存在**你这台机器的浏览器里**，不进画板数据：同一块板发给别人，人家该用自己的纸张和字号。

## 几条边界

- **超过一整页的长卡**会让它自己往下流（宁可多吃一张纸也不裁内容）。这种卡所在的那几页没有页脚页码，目录里给的是估出来的页码
- **横向 + 一栏**时可用高度只有一半，长卡很容易触发上面那条；横向建议配「两栏」
- 网页嵌入卡在纸上印的是卡片框与地址（跨源页面本来就截不出来），音视频卡印的是文件信息
