一种卡片 = 一个独立的插件目录。在顶栏「**卡片**」（卡片中心）里按需开关：停用只挡新建，**画板上已经有的卡照常渲染、数据一个字段都不丢**。

新装的画板默认只开常用的那几种，其余在卡片中心里打开就能用。

## 写字与摊想法

| 卡片 | 什么时候用 |
| --- | --- |
| **文本** | 默认选项。想不清楚用哪种就用它，正文支持 Markdown |
| **引用** | 别人说的话 / 原文摘录，带出处 |
| **待办** | 一张卡里一串勾选项，勾完自动算进度 |
| **导图** | 一张卡就是一棵思维导图，双击进全屏编辑 |

## 干活与追踪

| 卡片 | 什么时候用 |
| --- | --- |
| **任务** | 要被执行的事。可以一键转成 Issue、发起执行，进展回写到同一张卡（见 [任务与 Issue](/docs?doc=tasks)） |
| **规格** | 有固定字段的结构化信息：会议纪要 / 决策记录 / 选题 / 排障记录……见 [规格卡与信封](/docs?doc=specs) |

## 素材

| 卡片 | 什么时候用 |
| --- | --- |
| **链接** | 一条网址，自动抓标题 |
| **图片** / **PDF** / **音视频** | 拖进来就是一张卡。音视频就地播放，进度条可拖 |
| **网页** | 把别人的页面嵌进画板（受白名单限制，见卡片编辑器里的提示） |
| **图书** / **资料** | 要先配好对应的外部服务才会出现在工具条上 |

## 结构化表达

| 卡片 | 什么时候用 |
| --- | --- |
| **代码** | 语法高亮 + 一键复制，带文件名 |
| **表格** | Markdown 表格或 CSV 直接塞进来 |
| **图表** | Mermaid：流程图 / 时序图 / 甘特图，写语法 |
| **数据图** | 填数据不写语法的柱 / 线 / 饼图 |
| **SVG** | 直接贴一段 SVG |
| **Excalidraw** | 内嵌的手绘白板，双击进全屏画 |

### 在卡面上直接改文本

图表 / SVG / 代码 / 表格这四种卡，内容本身就是一段文本。卡面右下角有个「**编辑文本**」：点开就地改，
`⌘/Ctrl + Enter` 保存、`Esc` 放弃，不必先双击进抽屉。抽屉仍然管卡面上没有的那些字段——
代码卡的语言与文件名、表格卡的表标题。

## 收拾大板

| 卡片 | 什么时候用 |
| --- | --- |
| **分组框** | 就地圈一块地：框一拖里面整摊跟着走，可折叠 |
| **子画板** | 把一摊东西挪进**另一块板**，双击下钻进去 |

两者的区别与选择见 [分组框与子画板](/docs?doc=frames)。

## 换一种卡片

右键卡片 →「转换类型」。转换会尽量保留能对上的字段，对不上的**原样留着**——这是这个项目的透传铁律：任何一次「开板 → 保存」都不能毁掉任何字段，未知的、停用的类型的专属字段一律只存不洗。

## 卡片中心还管什么

除了 21 个卡片包的开关，同一个抽屉里还有**数据规格**（17 份内置规格的开关、字段说明、示例建卡）和**收卡片**（粘一段信封 JSON，干跑校验后落进画板）。见 [规格卡与信封](/docs?doc=specs)。
