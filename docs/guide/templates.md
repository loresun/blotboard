顶栏「**模板**」。选一个，卡片连带连线一次铺开，你只要往里填。

## 内置的 13 个

| 模板 | 用来干什么 |
| --- | --- |
| 九宫格创意 | 一个中心词，八个方向发散 |
| SCAMPER 改造 | 替代 / 合并 / 调整……七种改造角度 |
| 第一性原理 | 拆到不能再拆，再往回推 |
| 5 Why 追问 | 连问五次为什么，找到真因 |
| 5W1H 问题画布 | 把一个模糊的问题问清楚 |
| 六顶思考帽 | 六种视角轮着走一遍 |
| 黄金圈 Why-How-What | 从动机往外推到做法 |
| SWOT 分析 | 优劣势 × 机会威胁 |
| 跨界灵感发射器 | 从别的领域借解法 |
| 周复盘 | 做了什么 / 学到什么 / 下周改什么 |
| 选题立项骨架 | 一个选题从想法到能开工 |
| 一本书大纲骨架 | 章节结构先摆出来 |
| AI 落地需求诊断 | 判断一件事到底该不该上 AI |

## 两种用法

- **开一块新板**：选模板 → 直接得到一块铺好的板
- **插进当前板**：模板卡会落在当前视口附近，跟已有内容并存

## 待填提示

模板铺开的卡片里有占位内容。模板抽屉里会告诉你「还有几张模板卡没填」——填过的不再算数。这个计数是提醒你别把一块半成品当成想清楚了。

## 自己攒模板

把一块板整理成你要的样子，导出 JSON，就是一份可以反复用的骨架——下次导入回来改改名字就行。模板的真源是仓库里 `data/templates/` 下的 JSON 文件，格式和导出的画板 JSON 是一路的。
