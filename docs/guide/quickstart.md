跟着做一遍，五分钟走完「摊开 → 连线 → 整理 → 读 → 带走」这条主路。

## 1. 开一块板

左栏最上面「**新建**」。板名点顶栏中间那行字就能改。板多了以后可以分组：新建按钮右边的小箭头里有「新建分组 / 在某个分组里新建」。

## 2. 往上放东西

三种落卡方式，哪种顺手用哪种：

- **双击画布空白处** —— 就地开一张文本卡，直接打字
- **工具箱里点一种卡片** —— 落在视口中心，同时进入编辑
- **拖 / 粘贴** —— 图片、PDF、音视频文件拖进来就是一张卡；复制一条链接按 `⌘V` 就是链接卡

先别纠结用哪种卡。**大部分时候文本卡就够了**，后面想换类型，右键卡片里有「转换类型」。

## 3. 连起来

卡片四条边中间各有一个小圆点，从一个圆点拖到另一张卡上就是一条线。连线不只是好看——它有五种关系（关联 / 阻塞 / 前置 / 引用 / 产出），还有 1-5 的关系强弱。整理、分簇、导出都会拿它当依据。细节见 [连线有语义](/docs?doc=edges)。

## 4. 摆顺

顶栏右边「**整理**」，第一项「整齐化」是日常用的那个：**保留你摆出来的结构**，只对齐行列、理顺交叉的线、推开重叠。想换个角度看这堆东西，同一个菜单里还有十种摆法（流程串开、时间线、看板、四象限……），每一种都能撤销。见 [十一种整理](/docs?doc=organize)。

## 5. 读一遍

顶栏「**阅读**」（快捷键 `R`）：整块板按阅读顺序压成一条序列，一张卡摊满整屏，`←` `→` 翻卡。这是检查「这块板讲清楚了没有」最快的方式——摆得再漂亮，读一遍串不起来就是没想清楚。

## 6. 带走

顶栏「**导出**」。默认那项「排版导出 · HTML」给的是一份**自包含的单文件**：零外链、离线双击能开、直接打印就是 A4 的 PDF。另外还有 PNG（整块板截图）、Markdown（给人看 / 喂给模型）、JSON（可以原样改回来）。
